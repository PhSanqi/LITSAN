# Addendum 1 to CRITERIA.md — written after the smoke run, before the main run / CRITERIA.md 附录 1——冒烟运行后、主运行前写成

- EN: Observation on the 8 smoke questions: the gate reported `confidence` as certainty in its own verdict (e.g. `sufficient: false, confidence: 97`), not as the probability that the context is sufficient. The gate prompt stays unchanged (frozen). Only the ranking used for the risk–coverage curve and AURC is fixed here: score = 100 + confidence when `sufficient` is true, 100 − confidence when false (sufficient verdicts always rank above insufficient ones; within each verdict, more certain sufficient ranks higher and more certain insufficient ranks lower). Ties by a seeded random order (seed 20261107). The alternative reading (score = confidence inside the insufficient group) is reported as a sensitivity check only. The binary verdict, H1, H1b and every decision rule are unchanged.
- 中文：8 道冒烟题上的观察：门控把 `confidence` 当作对自身结论的把握度（例如 `sufficient: false, confidence: 97`），而不是"上下文充分的概率"。门控提示词保持不变（已冻结）。此处只固定风险–覆盖曲线与 AURC 所用的排序：`sufficient` 为真时得分 = 100 + confidence，为假时得分 = 100 − confidence（充分结论总排在不充分结论之前；同一结论内，越确定"充分"越靠前，越确定"不充分"越靠后）。平分按种子随机序（种子 20261107）。另一种解读（不充分组内得分 = confidence）仅作为敏感性检查报告。二元结论、H1、H1b 与所有判定规则均不变。
