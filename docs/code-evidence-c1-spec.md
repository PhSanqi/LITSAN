# C1 code evidence specification / C1 代码证据规格

- EN: Scope is design A phase C1: deterministic TS/JS modules/imports/literal constants, declared layers, bootstrap and review integration. C2 drift/UI and C3 Python/C++ are deferred. / 中文：仅实现设计 A 的 C1；C2 漂移/UI 和 C3 其他语言不纳入。
- EN: Add .memhub/layers.json mirroring contracts, core, archify, shell and engine boundaries; shell includes src/** outside the three composite packages; vendor contents remain excluded. / 中文：镜像五个已有单元；shell 排除三个独立包；不扫描 vendor 内容。
- EN: Scan only the existing resolved project workspace on demand, without executing source, calling models, starting workers or adding dependencies/tools/routes. / 中文：按需只读既有项目工作区，不执行代码、调用模型、启动 worker 或新增依赖/接口。
- EN: Produce bounded code refs with revision/path/line ranges and snippets <=400 chars; complete clean Git scans use commit identity, dirty/non-Git/truncated scans use content identity. Caps: 1000 files, 10 MiB total, 256 KiB/file, 5-second traversal budget, 200 constants, 64 KiB output. / 中文：引用绑定版本、路径与行号；完整干净 Git 扫描使用提交标识，其余使用内容标识；设置上述读取和输出上限及遍历时间预算，截断显式报告。
- EN: Respect Git ignore rules; non-Git scanning applies conservative nested ignore exclusions. Reject traversal and symlinks; skip build/vendor/binaries, .env and credential paths; never emit secret-like literal values. / 中文：遵守忽略规则；非 Git 使用保守嵌套排除；拒绝越界/符号链接并过滤机密。
- EN: Reuse JSON/YAML parsers already installed; TS/JS and TOML extract only conservative literal declarations, never evaluate expressions. / 中文：复用现有 JSON/YAML 解析器；TS/JS、TOML 仅抽取有限字面量，不求值。
- EN: Bootstrap includes bounded code evidence and admits exact refs. Submit rescans and rejects stale/foreign code refs. Node layers are computed from distinct cited source files: >=80% same declared layer, otherwise mixed; no code/rule means no automatic layer. / 中文：bootstrap 提供代码证据；submit 重扫拒绝过期/跨范围引用；按不同被引文件确定分层。
- EN: Accepted map writes retain compact immutable code snapshots beside that account/project architecture; dry runs do not persist them. Reviews hydrate exact retained snippets without replacing them with changed code. / 中文：仅成功写图路径保存紧凑不可变代码快照；演练不写；评审使用精确历史片段。
- EN: Reach: layers manifest; code contract/scanner/projection; architecture source; bootstrap assembly/submit; maintenance context/review; tests and context:check. Existing MCP schema and hard Architecture stay unchanged. / 中文：改动覆盖声明、契约、扫描、派生、架构源与引导/评审及测试；既有 MCP schema 与硬架构不变。
- EN: Gates: isolated security/determinism/cap/stale-ref/layer-threshold tests plus bootstrap/review integration; full TMPDIR=/tmp/mhd npm test and zero module-boundary violations; fast-forward only, preserve external scripts, remove task worktree after landing. / 中文：专项与全量验收后仅快进合入，保留外部脚本并清理本任务 worktree。
